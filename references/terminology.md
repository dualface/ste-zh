# 術語與固定譯法

本文件規定 ste-zh 使用的全部關鍵詞。使用本 skill 時，必須按本表翻譯和用詞。表中沒有的詞，按 R1 在輸出的「術語」節中自行固定。

## 1. ASD-STE100 關鍵詞的中文譯法

討論 ASD-STE100 本身，或向讀者解釋規則來源時，使用以下譯法。首次出現時寫「中文（英文）」，之後只寫中文。

## 2. 情態詞

全文只用以下三個情態詞。

| 用詞 | 詞義 | 不得使用的近義詞 |
|---|---|---|
| 必須 | 強制要求 | 應、應當、應該、需要、務必、要 |
| 不得 | 禁止 | 不應、不要、避免、禁止、切勿、不允許 |
| 可以 | 允許，不強制 | 可、能夠、允許、可選 |

本表只限制情態用法。情態用法指表示要求、禁止或允許的用法。以下用法不受本表限制：

- 「需要」表示缺少或依賴某物。例：「讀者需要的證據」。
- 固定用詞「要做」。見第 5 節。

例外：引用來源原文時，保留原文用詞，並用引號標出。

## 3. 虛化動詞替換表

以下寫法把動作包裝成名詞。必須改為直接動詞。

| 不得使用 | 改寫為 |
|---|---|
| 對 X 進行修改 / 處理 / 檢查 | 修改 / 處理 / 檢查 X |
| 實現 X 功能 | 增加 X；或寫出 X 的具體行為 |
| 予以 X / 加以 X | X |
| 做好 X 工作 | X |
| 完成 X 的操作 | X |
| 將會 X | 會 X |
| 進行 X | X |
| 作出 X 決定 | 決定 X |
| 透過 X 的方式 | 用 X |
| 存在 X 問題 | 寫出具體現象 |
| 有一定的 X | 寫出具體的量；沒有量時刪除 |

「處理」本身也是虛化動詞。能寫出具體動作時，不用「處理」。

## 4. 狀態詞

寫工作狀態時，只用以下詞，並只按表中的詞義使用。

| 狀態詞 | 詞義 | 不得替換為 |
|---|---|---|
| 已完成 | 動作全部執行，結果符合要求。 | 搞定、OK、done、基本完成 |
| 部分完成 | 一部分動作已執行。必須列出沒有執行的部分。 | 基本完成、大致完成 |
| 未開始 | 沒有執行任何動作。 | 待辦、TODO |
| 進行中 | 動作已開始，沒有結束。 | 處理中、跟進中 |
| 已驗證 | 執行了檢查，檢查通過。必須寫出檢查方法。 | 已測試、應該沒問題 |
| 未驗證 | 沒有執行檢查。必須寫出原因。 | 理論上可行、應該可以 |
| 失敗 | 執行了動作或檢查，結果不符合要求。必須寫出失敗的輸出。 | 有點問題、不太行 |
| 跳過 | 有意沒有執行。必須寫出原因。 | 略過、忽略 |
| 阻塞 | 缺少條件，不能繼續。必須寫出缺少的條件。 | 卡住、受阻 |
| 未確認 | 事實沒有核實。必須寫出核實方法。 | 可能、大概、應該是 |

「完成」不得單獨用來表示「已驗證」。改動已完成但沒有檢查時，寫「已完成，未驗證」。

## 5. 模板的固定用詞

| 用詞 | 用途 | 不得替換為 |
|---|---|---|
| 術語 | 定義專用詞的節 | 名詞解釋、詞彙表、定義 |
| 共同條件 | 所有項都適用的事實或約束 | 前提、背景、通用約束 |
| 問題 | 一項工作的現狀 | 現狀、缺陷描述、痛點 |
| 要做 | 一項工作必須達到的可檢查結果 | 方案、措施、修復內容、TODO |
| 改動 | Agent 修改的檔案或設定 | 變更內容、修改點、diff |
| 驗證 | 檢查及其結果 | 測試情況、自測 |
| 未做 | 範圍內沒有執行的事 | 遺留、後續、TODO |
| 現象 | 使用者看到的行為 | 表現、症狀 |
| 原因 | 現象的直接來源 | 根因分析、問題所在 |
| 證據 | 支援一個事實的來源位置 | 依據、出處 |
| 建議 | Agent 推薦的下一個動作 | 方案、解決思路 |
| 待確認 | 由使用者決定的事項，或來源缺少的內容 | 風險、TBD、遺留問題 |
| 推薦 | 選項列表中 Agent 推薦的一項 | 建議選擇、首選 |

## 6. 標點與混排

- 中文正文用全形標點：「，。；：（）」。
- 引用介面文字或強調詞語用直角引號「」。
- 程式碼、命令、路徑、識別碼寫在反引號內，內部保持半形。
- 中文與英文單字、數字之間加一個半形空格。中文與全形標點之間不加空格。
